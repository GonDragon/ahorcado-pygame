# Juego del Ahorcado - Segundo Parcial Programación 1

Este proyecto es el desarrollo de un clásico Juego del Ahorcado utilizando la biblioteca Pygame, como parte del segundo parcial de la materia Programación 1.

El trabajo cumple con los siguientes requisitos:

- Desarrollo sin programación orientada a objetos.
- Separación del código en módulos, cada uno con una responsabilidad específica.
- Uso de listas, diccionarios, estructuras condicionales y manejo de archivos.
- Lectura de las palabras desde un archivo externo.
- Representación gráfica de los errores mediante el dibujo progresivo del ahorcado.
- Incorporación de un personaje en pantalla, cuya dinámica fue elegida por el equipo.
- Validación de las letras ingresadas por el usuario, evitando repeticiones.
- Sonido de error en cada fallo.
- Detección de fin del juego, mostrando mensajes de victoria o derrota.
- Comentarios en el código explicando línea por línea su funcionamiento.
